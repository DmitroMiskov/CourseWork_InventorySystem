================================================================================
          ІНСТРУКЦІЯ ТА ПОСЛІДОВНІСТЬ КОМАНД ДЛЯ ЗАПУСКУ ПРОЄКТУ
                  Warehouse Inventory System (Складський облік)
================================================================================

Цей документ містить покрокові інструкції для двох варіантів запуску:
  ВАРІАНТ 1: Запуск через Docker Compose (Рекомендований, в один клік)
  ВАРІАНТ 2: Ручний запуск компонентів локально (Local Development)

--------------------------------------------------------------------------------
ВИМОГИ ДО СИСТЕМИ (PREREQUISITES)
--------------------------------------------------------------------------------
Для Варіанту 1 (Docker):
  - Docker Desktop (з увімкненим Docker Compose)

Для Варіанту 2 (Локальний запуск):
  - .NET 9.0 SDK (перевірка: dotnet --version)
  - Node.js (v20 або v22 LTS) та npm (перевірка: node -v, npm -v)
  - PostgreSQL 15+ (або запущений контейнер PostgreSQL)


================================================================================
ВАРІАНТ 1: ЗАПУСК ЧЕРЕЗ DOCKER COMPOSE (ШВИДКИЙ ТА ПОВНИЙ)
================================================================================

Цей варіант автоматично збирає та запускає всі 4 сервіси:
  1. Базу даних PostgreSQL 15
  2. Обчислювальний ML-мікросервіс (Python 3.11 + FastAPI + scikit-learn)
  3. Backend (.NET 9 Web API з Hot Reload)
  4. Frontend (React + TypeScript + Vite)

КРОК 1. Відкрийте термінал (PowerShell або командний рядок) у корені проєкту:
   cd E:\Coursework\InventorySystem

КРОК 2. Запустіть контейнери командою:
   docker compose up --build

   (Або у фоновому режимі):
   docker compose up -d --build

КРОК 3. Доступ до працюючих сервісів:
   - Веб-інтерфейс (Frontend):  http://localhost
   - Swagger API (.NET бекенд): http://localhost:8080/swagger
   - Swagger ML (Python сервіс):http://localhost:8000/docs
   - База даних PostgreSQL:     localhost:5432 (User: postgres, Password: password, DB: inventory_db)

КРОК 4. Зупинка контейнерів:
   docker compose down


================================================================================
ВАРІАНТ 2: РУЧНИЙ ЗАПУСК ДЛЯ РОЗРОБКИ (КРОК ЗА КРОКОМ)
================================================================================

--------------------------------------------------------------------------------
Крок 1. Запуск бази даних PostgreSQL
--------------------------------------------------------------------------------
Якщо у вас немає встановленого локального PostgreSQL, найпростіше підняти лише його через Docker:
   docker run --name inventory-db -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=password -e POSTGRES_DB=inventory_db -p 5432:5432 -d postgres:15-alpine

Переконайтеся, що рядок підключення у `src/Inventory.API/appsettings.json` відповідає вашому порту:
   "ConnectionStrings": {
     "DefaultConnection": "Host=localhost;Port=5432;Database=inventory_db;Username=postgres;Password=password"
   }

--------------------------------------------------------------------------------
Крок 2. Збірка та запуск Backend API (.NET 9)
--------------------------------------------------------------------------------
1. Відкрийте перший термінал та перейдіть у каталог API:
   cd E:\Coursework\InventorySystem\src\Inventory.API

2. Відновіть пакети та перевірте збірку:
   dotnet restore
   dotnet build

3. Запустіть бекенд:
   dotnet run --launch-profile http

   (Або з автоматичним перезавантаженням при зміні коду):
   dotnet watch run --launch-profile http

4. Перевірте працездатність:
   Відкрийте у браузері: http://localhost:8080/swagger

--------------------------------------------------------------------------------
Крок 3. Збірка та запуск Frontend (React 19 + TypeScript + Vite)
--------------------------------------------------------------------------------
1. Відкрийте другий термінал та перейдіть у каталог фронтенду:
   cd E:\Coursework\InventorySystem\frontend

2. Встановіть залежності (якщо запускаєте вперше):
   npm install

3. Запустіть сервер розробки:
   npm run dev

4. Перевірте працездатність:
   Відкрийте у браузері: http://localhost:5173


================================================================================
ПОЧАТОК РОБОТИ В СИСТЕМІ (ГАРАНТОВАНИЙ СУПЕРКОРИСТУВАЧ / ВХІД)
================================================================================
При кожному запуску бекенду система автоматично перевіряє наявність суперкористувача
в базі даних (якщо базу чи контейнери було видалено, він створюється автоматично):

  👑 СТАНДАРТНІ ДАНІ СУПЕРКОРИСТУВАЧА (ADMIN):
     • Логін:    admin
     • Пароль:   Admin123!
     • Роль:     Admin

1. Відкрийте веб-інтерфейс у браузері (http://localhost або http://localhost:5173).
2. Введіть логін `admin` та пароль `Admin123!` для входу безпосередньо в систему.
3. Доступні розділи системи:
   - "Склад"       — список товарів, пошук, фільтри, імпорт/експорт Excel/CSV, списання/видача.
   - "Категорії"   — створення та редагування категорій продукції.
   - "Контрагенти" — управління постачальниками та клієнтами.
   - "Дашборд"     — аналітика, KPI, графіки залишків та фінансова статистика.
   - "Персонал"    — управління користувачами (доступно тільки ролі Admin).

Примітка: Ви також можете зареєструвати додаткових користувачів через вкладку
"Реєстрація" на формі входу або керувати ними у вкладці "Персонал".
